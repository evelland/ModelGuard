## Process
1. Extract official requirements and times from course syllabus or faculty communications; link original sources.
2. Record all hard deadlines on shared calendar; link calendar entries here.
3. For major presentations and reports, open GitHub Issues for first draft (T−7 days), group review (T−3 days), and final version (T−1 day). Adjust if announcement provides less lead time.
4. At each weekly meeting verify the next two deadlines, submission owner, and remaining blockers.
5. After a deliverable, link final artifact and capture faculty feedback as new issues.
